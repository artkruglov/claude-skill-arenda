# Поиск квартиры в аренду

Массовый разбор: прогнать сотни объявлений, отсеять мусор по объективным признакам, глубоко разобрать выжившие два десятка, выдать ранжированный топ.

Принцип: **дом отсеивается раньше квартиры**. Хорошая квартира в плохом доме остаётся плохим вариантом, а проверка дома дешевле — один раз на десятки лотов.

## Что уточнить до старта

Спросить одним блоком, не по одному:

1. Город и район или привязка к точке (работа, школа, метро) + максимальное время в пути
2. Бюджет: потолок аренды и готовность платить коммуналку сверху
3. Состав семьи → сколько нужно **изолированных спален** (не «комнат»)
4. Срок аренды, дети, животные, нужна ли регистрация
5. Мебель: нужна полностью, частично или заезжают со своей

Если человек говорит «сам решай» — брать разумные умолчания и явно назвать их в итоге.

## Этап 1. Массовый сбор

### Площадки

| Площадка | Чем полезна | Подвох |
|---|---|---|
| Циан | Самая полная база, фильтр по ЖК, год постройки, серия дома | Игнорирует часть URL-фильтров, ленивая подгрузка карточек |
| Яндекс.Недвижимость | Больше собственников, панорамы улиц для проверки вида | Меньше технических данных о доме |
| Авито | Частники без комиссии | Много дублей и объявлений-приманок |

### Правила сбора

**Фильтры в URL не всегда применяются.** После загрузки проверить заголовок выдачи: если число результатов не похоже на ожидаемое, фильтр отвалился. Рабочий обход — собрать шире и отфильтровать у себя.

**Карточки подгружаются лениво.** Перед парсингом: прокрутить вниз, подождать 3 секунды, нажать End, подождать ещё 5. Без этого со страницы снимется половина.

**Сортировка по площади** (`sort=area_order`) удобнее сортировки по цене: один проход даёт понятную карту того, какие метражи вообще есть в этом доме или районе.

Сборщик для страницы выдачи Циан — выполнить в консоли вкладки:

```js
var out=[];
document.querySelectorAll('article').forEach(function(a){
  var t=a.innerText;
  var L=t.split('\n').map(function(s){return s.trim()}).filter(Boolean);
  var ma=t.match(/([0-9]+[,.]?[0-9]*)\s*м²/);
  var mf=t.match(/(\d+)\/(\d+)\s*эт/);
  var mr=t.match(/(\d)-комн/);
  var pl=L.find(function(x){return /₽/.test(x)&&!/м²/.test(x)})||'';
  var pr=pl.replace(/[^0-9]/g,'');
  var ad=L.find(function(x){return /ул\.|улица|проспект|переулок|бульвар/.test(x)})||'';
  var who=/Собственник/i.test(t)?'S':(/Агент|агентств/i.test(t)?'A':'?');
  var lnk=(a.querySelector('a[href*="/rent/flat/"]')||a.querySelector('a[href*="/flat/"]')||{}).href||'';
  var id=lnk.match(/flat\/(\d+)/);
  if(id) out.push([id[1],(ma?ma[1]:'?').replace(',','.'),mf?mf[1]+'/'+mf[2]:'?',
                   Math.round((+pr||0)/1000),who,mr?mr[1]+'k':'?',ad.slice(0,40)].join('|'));
});
out.length+'\n'+out.join('\n')
```

Поля: `id | площадь | этаж/этажность | цена тыс ₽ | продавец | комнат | адрес`.

### Обязательная дедупликация

Одну квартиру часто ведут несколько агентств. Совпадение **адрес + площадь + этаж** — это дубль. Схлопнуть в одну запись, сохранив все ссылки: разные продавцы по-разному торгуются, а иногда среди них есть собственник напрямую.

## Этап 2. Инсоляция по геоданным

Самая недооценённая характеристика. «Светлая квартира» в объявлении не значит ничего — считать.

### Физика для широты Москвы (55,75°)

Максимальная высота солнца над горизонтом:

| Дата | Высота |
|---|---|
| 21 декабря | **10,8°** |
| 21 марта / 21 сентября | 33,9° |
| 21 июня | 57,7° |

Отсюда главное правило: **зимой солнце поднимается всего на 10,8°**. Препятствие закрывает зимнее солнце, если угол на его верх больше этого. Девятиэтажка (27 м) загораживает зимнее солнце на расстоянии до 140 м.

Часы прямого солнца по сторонам света, открытый горизонт:

| Окна | 21 дек | 21 мар | 21 июн |
|---|---|---|---|
| Юг | 6,8 | 5,2 | 3,8 |
| Юго-восток / юго-запад | 3,4 | 5,9 | 4,9 |
| Восток / запад | 0 | 3,3 | 6,7 |
| Северо-восток / северо-запад | 0 | 0 | 3,7 |
| Север | 0 | 0 | 0 |

Летом южное окно получает меньше часов, чем восточное — солнце проходит высоко и быстро пересекает южный сектор. Зимой юг выигрывает вчистую.

### Скрипт расчёта

Полная версия — `scripts/insolation.py`. Ядро:

```python
import math

def declination(day):
    return 23.45 * math.sin(math.radians(360.0 * (284 + day) / 365.0))

def solar_position(lat, dec, hour_angle):
    la, d, h = map(math.radians, (lat, dec, hour_angle))
    sin_alt = math.sin(la)*math.sin(d) + math.cos(la)*math.cos(d)*math.cos(h)
    alt = math.degrees(math.asin(max(-1, min(1, sin_alt))))
    cos_az = (math.sin(d) - math.sin(math.radians(alt))*math.sin(la)) / \
             (math.cos(math.radians(alt))*math.cos(la) + 1e-9)
    az = math.degrees(math.acos(max(-1, min(1, cos_az))))
    return alt, (360 - az if hour_angle > 0 else az)

def sun_hours(lat, window_az, day, obstruction=0.0, fov=90.0):
    """Часы прямого солнца. window_az: 0=север, 90=восток, 180=юг, 270=запад."""
    dec = declination(day)
    minutes = 0
    for m in range(0, 24*60, 10):
        alt, az = solar_position(lat, dec, (m/60.0 - 12.0) * 15.0)
        if alt <= obstruction:
            continue
        if abs((az - window_az + 180) % 360 - 180) <= fov/2:
            minutes += 10
    return round(minutes/60.0, 1)

def obstruction_angle(height_m, distance_m, observer_height_m=0.0):
    effective = max(0.0, height_m - observer_height_m)
    return round(math.degrees(math.atan2(effective, distance_m)), 1)

# дни: 355 = 21 дек, 80 = 21 мар, 172 = 21 июн
```

Этажность в метры: умножать на 3,0 (современный монолит), 2,8 (панель), 3,2 (сталинка).

### Как получить исходные данные

1. **Азимут окон.** В объявлении («окна на юго-запад», «на две стороны»). Если не указано — определить по карте: найти дом, посмотреть ориентацию фасада и расположение квартиры по этажу. Для углового лота считать оба направления.
2. **Препятствия.** На спутниковой карте измерить расстояние до ближайших зданий по направлению окон и оценить их этажность.
3. **Этаж квартиры.** Чем выше, тем меньше влияют окрестные дома: препятствие в расчёте уменьшается на высоту квартиры над землёй.

### Вердикт

| Зимних часов | Оценка |
|---|---|
| 5+ | Отлично, солнце в комнате зимой |
| 2–5 | Нормально |
| 0,5–2 | Мало, зимой будет сумрачно |
| 0 | Прямого солнца зимой нет вообще |

Квартира, которая зимой получает ноль, может быть приемлема, если это спальня или если окна выходят на яркий открытый двор — отражённого света хватит. Но для гостиной и детской это дисквалифицирующий признак, и его надо назвать прямо.

## Этап 3. Планировка

### Ловушка комнатности

Площадки считают кухню-гостиную комнатой. «Трёхкомнатная» сплошь и рядом означает кухню-гостиную и **две** спальни. Семье с двумя детьми это не подходит.

Считать не комнаты, а **изолированные спальни с дверью из холла**. Признаки в тексте: «три изолированные», перечисление размеров («19, 16 и 15 м²»), «мастер-спальня + две комнаты». Формулировки «можно организовать», «свободная планировка», «евро-четыре» означают, что спален по факту меньше — уточнять.

### Эффективная площадь

```
эффективная = жилая + кухня
эффективность = эффективная / общая
```

| Эффективность | Что это значит |
|---|---|
| 85%+ | Отлично, коридоров почти нет |
| 75–85% | Норма |
| ниже 70% | Четверть площади — коридоры и подсобки, за которые вы платите |

На 100 м² разница между 85% и 65% — это двадцать метров, то есть целая комната.

Метрика слепа к качеству: она не видит тёмных внутренних комнат и неудобной геометрии. Считать её фильтром, а не вердиктом.

### Красные флаги планировки

- Кухня менее 10 м² при общей площади больше 80 — жить на такой кухне вчетвером не получится
- Проходные комнаты — считать их спальнями нельзя
- Длинный внутренний коридор без окон
- Все окна в один двор-колодец
- Второй уровень или антресоль, не отражённые в документах БТИ

## Этап 4. Дом и окружение

Проверять один раз на все лоты в этом доме:

- **Год и тип.** Панель до 1970-х — слабая шумоизоляция. Монолит 2000-х и новее — обычно лучше. Сталинка — высокие потолки, но старые коммуникации.
- **Этажность и лифты.** В высотках смотреть число квартир на этаже и количество лифтов. Больше 80 квартир на лифт — утренние очереди.
- **Отзывы жителей.** Искать на 2ГИС, форумах дольщиков, в чатах дома. На агрегаторах отзывы часто заказные: признак — поток коротких пятёрок. Доверять развёрнутым текстам и единичным единицам, а не средней оценке.
- **Двор и парковка.** Есть ли машины во дворе, охраняется ли территория.
- **Что рядом.** Промзона, шоссе, железная дорога, ТЭЦ — проверить по карте в радиусе 2 км.

### Доступность

Считать **пешее время до метро по маршруту**, а не по прямой: реальный путь длиннее примерно на 15–20%, плюс переходы и светофоры. Проверять, одна ветка или пересадка до нужной точки — это важнее числа минут до ближайшей станции.

## Этап 5. Специфика аренды

То, что не имеет значения при покупке, но решает всё при найме.

### Кто сдаёт

Собственник напрямую — нет комиссии, быстрее договориться. Агент — комиссия обычно от половины до целой месячной платы.

Признаки объявления-приманки: цена заметно ниже рынка, фотографии из стока или из другой квартиры, адрес указан приблизительно, при звонке «эту уже сдали, но есть похожая». Сверять фото с панорамами улиц.

### Реальный платёж в месяц

Складывать всё, а не только аренду:

- Аренда
- Коммуналка: включена или сверху, с счётчиками или по нормативу
- Интернет
- Парковка, если нужна
- Залог (обычно месяц) и комиссия агента — разовые, но влияют на вход

### Мебель и техника

Фиксировать **поимённо в акте приёма-передачи**, с фотографиями и указанием дефектов. Формулировка «с мебелью» в объявлении ничего не гарантирует: часть вещей собственник нередко вывозит перед въездом.

### Договор

- Срок и условия продления, индексация платы
- За сколько предупреждают о выселении, за сколько — вы
- Кто оплачивает ремонт при поломке техники и сантехники
- Дети, животные, курение, гости
- Возможность регистрации, если нужна
- Условия возврата залога и что считается нормальным износом
- Проверить право сдавать: выписка ЕГРН или доверенность, паспорт собственника

## Этап 6. Скоринг и выдача

Считать баллы только по проверенным полям. Не домысливать недостающее — помечать как «уточнить».

| Критерий | Вес | Как считать |
|---|---|---|
| Изолированных спален | 25 | Хватает нужного числа — полный балл, на одну меньше — половина, меньше — ноль |
| Зимняя инсоляция | 20 | По таблице вердикта выше |
| Полный платёж в месяц | 20 | Относительно медианы по выборке |
| Эффективность площади | 10 | По таблице выше |
| Дорога до ключевой точки | 10 | Пешком, одной веткой, с пересадкой |
| Состояние и мебель | 10 | Готова к въезду / нужны вложения |
| Дом и двор | 5 | Отзывы, тип, парковка |

### Формат итога

**Топ-5–7 с обоснованием.** По каждому: что даёт и чем за это платите. Второе обязательно — вариант без минусов означает, что минус не нашли.

**Отдельно — что отсеяно и почему**, сгруппированно: «22 лота убраны по дому», «7 по цене выше рынка», «4 дубля». Человек должен видеть, что выборка пройдена целиком, а не что показали первые попавшиеся.

**Вопросы на просмотр.** Собрать в отдельный список то, что проверяется только на месте:

- Открыть окна, послушать улицу
- Проверить напор воды и температуру горячей
- Включить всю технику
- Посмотреть на углы и под окнами: следы плесени и протечек
- Мобильная связь внутри квартиры
- Шум от соседей и из подъезда
- Приехать в час пик, оценить парковку и лифт

### Чего не делать

- Не выдавать «подходит идеально» — называть конкретный минус у каждого варианта
- Не принимать текст объявления за факт: продавец заинтересован. Проверять площадь по документам, планировку по БТИ, сроки по выписке
- Не ранжировать по цене за метр в отрыве от качества: самый дешёвый метр обычно в доме, где что-то не так
